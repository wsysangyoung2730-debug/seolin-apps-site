# SEOLIN Apps

서린태권도에서 만든 앱의 소개, 사용 안내, 지원 및 개인정보처리방침을 제공하는 공식 웹사이트입니다.

- TCON Maker by SEOLIN
- BLOG COVER MAKER by SEOLIN
- JUMPROPE PLAYER by SEOLIN

## 개발 규칙

- `main`: 출시용 브랜치
- `develop`: 개발 통합 브랜치
- 작업 브랜치: `태그/#이슈번호-작업범위`
- 커밋: `[소문자 태그] 한글 명령조 제목` (50자 이내)
- 작업 전 이슈를 작성하고 최신 `develop`을 병합한 뒤 `develop` 대상으로 PR을 생성합니다.
- 완료한 기능은 PR을 통해 `develop`에 병합합니다.
